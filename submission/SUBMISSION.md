# 观澜日收盘自选股监控

观澜面向需要持续关注股票目标价、又不想反复手动查价的个人投资者。用户用自然语言描述关注条件，核对并修改结构化规则后启用；系统在云端检查真实日收盘数据，保留提醒与每次判断依据。

产品：https://ucdte4eh02uv.meoo.info

源码：https://github.com/Yilin291/InvestmentMonitor

产品采用受保护的演示账户，演示口令通过提交平台的私密渠道另附。不要将口令、供应商Key或调度凭证放入公开README。

## 核心体验

1. 按名称或代码选择沪深A股，或输入明确的自然语言规则。
2. 检查生成的草稿，修改阈值、AND/OR关系和冷却时间；AI不会自动启用任务。
3. 试运行，查看真实收盘价、交易日期、来源及满足或不满足的原因。
4. 明确确认启用。关闭页面后，由Cloudflare Cron调用正式业务接口；产品和数据库运行在秒悟。
5. 返回监控台查看执行、站内提醒、未提醒原因与版本变化。可以暂停、恢复、编辑或删除任务，删除后保留只读证据。

另支持指定日期时间的一次性提醒。所有页面时间使用北京时间；日收盘数据日期仅表示交易日，不冒充逐笔成交时刻。

## 核心设计

实体、数据和关系分别记录：Instrument存标的信息，Observation存真实观察，Evidence关联观察，Run关联不可变RuleVersion。运行状态与规则版本分离。

确定性执行器负责十进制比较、三值AND/OR、事件段和冷却；模型负责将自然语言转换成可检查草稿。数据库事务在写入提醒前复核租约、版本、生命周期和归属，避免重复通知与在途旧规则生效。

价格使用沪深A股最新已完成交易日、不复权、CNY日收盘。供应商为扶摇，iFinD用于早期数据能力及元数据验证。缺失、过期、冲突或覆盖不明时降为unknown，不将未知当成不满足，也不补造漏检期间的行情。

## 已有真实运行证据

- 独立云调度曾连续处理日期任务及三个股票任务；真实收盘条件分别得到true和false，产生4条Run、4条Evidence、3条Notification。
- 同键重放未重复生成业务提醒，跨产品发布后记录保留。
- 30分钟31个计划时隙中有一次健康探测超时，下一分钟恢复；没有把该窗口描述为零故障。
- 通过手动领取后中断注入故障，由独立云调度在租约到期后接管，生成唯一通知，旧执行失效。这是故障注入恢复，不是自然行情穿越。
- 同实例隔离恢复验证15张业务表内容一致；不等于跨实例灾备。

对应文件见EVIDENCE_INDEX.md。当前前端为 static v14、后端为 Deno v20；发布清单见 release-static-v14.json，最终验收见 FINAL_ACCEPTANCE.md。

## 适用边界

- 本版本为日收盘监控，不提供盘中实时行情、自动交易或投资收益承诺。
- 提醒是站内持久化通知，不发送短信、邮件或移动端推送。
- 单个演示账户，最多10个任务；每个tick最多处理1个任务，不承诺所有任务每5分钟检查或分钟级准时提醒。
- 公告、热度、跨类型复杂组合尚未开放。没有以模拟市场数据充当真实运行。
- 价格反复穿越、冷却及部分故障场景由隔离TEST验证；周末真实数据验证不能证明市场已发生多次穿越。
