# 当前版本演示脚本

总长约120秒，实际录制最终线上页面。使用已存在的真实自动结果，不等待现场行情变化，不人为触发tick冒充自动。镜头避开口令输入、模型Key和后台凭证。

| 时间 | 画面和讲解 |
| --- | --- |
| 0–15秒 | 监控台：用于持续关注股票日收盘目标价，离开页面后云调度仍检查 |
| 15–40秒 | 输入明确股票和日收盘阈值，展示可编辑草稿；模型不直接启用 |
| 40–60秒 | 真实预览：股票全称/代码、收盘价、交易日期、不复权/CNY、条件结果；展示确认启用入口 |
| 60–85秒 | 打开已经真实自动执行的任务：执行时间、云调度来源、提醒和证据；说明不是此刻盘中成交 |
| 85–100秒 | 打开真实不满足任务，解释为什么没有提醒；展示连续满足不重复提醒的记录 |
| 100–115秒 | 展示版本/暂停或已保存的恢复与空档记录；如为故障注入证据，明确说明 |
| 115–120秒 | 边界：日收盘、站内提醒、单演示账户；源码和测试证据随附 |

如果新界面尚未显示恢复专门卡片，使用已有真实详情入口，不制作假的UI或状态。视频中不声称零延迟、零失败、跨实例灾备或真实市场多次穿越。
